# Starter preset: the 29 face poses as mixes of the 52 Apple ARKit
# blendshapes. Use it on a blendshape head with ARKit-named targets:
#     AddFaceShapesFromSelection();   (select the head mesh)
#     SaveNeutral();                  (all sliders at 0)
#     ApplyShapePreset("C:/path/ARKit_FacePoses.txt");
#
# Format:  PoseName=target:weight target:weight ...
# "Left" in ARKit names is the character's own left, same as _L here.
# This is a starting point. Preview every pose, and recapture any that
# don't read right on your character (dial the sliders, CapturePose(N)).
# Copy this file and rename the targets for other naming schemes (CC4 etc).
